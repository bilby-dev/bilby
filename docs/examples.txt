========
Examples
========

You can run and edit all of the example scripts in your browser, with no
installation, on the `interactive examples
<https://bilby-dev.github.io/examples/>`_ page. The links below open each
example there.

General inference examples
--------------------------

* :example:`A simple Gaussian likelihood <core_examples/gaussian_example.py>`:
  a good example to see how to write your own likelihood.
* :example:`Linear regression for unknown noise <core_examples/linear_regression_unknown_noise.py>`:
  fitting to general time-domain data.
